# Ponto do Estágio

[Acessar o site](https://leticiabeatriz.github.io/ponto-estagio/)

Controle de jornada e banco de horas, com salvamento no Supabase.

Cadastro por convite com e-mail, nome e PIN de quatro dígitos. Entre com e-mail e PIN; o navegador lembra sua conta. E-mail somente para recuperar o PIN.

Use **Importar** para trazer o `db.json` do programa antigo.
